# Slotto Icon Concepts

## 01 Calendar Spark

File: `slotto-icon-01-calendar-spark.svg`

Meaning: calendar + automatic suggestion. This is the strongest fit for "generate candidate times".

## 02 Calendar Check

File: `slotto-icon-02-calendar-check.svg`

Meaning: calendar + confirmed schedule. More business-like and direct.

## 03 Slot Picker

File: `slotto-icon-03-slot-picker.svg`

Meaning: multiple candidate slots with one selected. Best match for the Slotto product concept.

## 04 Brand S Calendar

File: `slotto-icon-04-brand-s-calendar.svg`

Meaning: branded S mark with calendar badge. Better if the product wants stronger brand identity.

## Recommendation

Use `slotto-icon-03-slot-picker.svg` for early product testing because it communicates the core workflow: generate several options, then choose one.

The selected extension source icon is `icon.svg`, copied from concept 03.
Chrome uses generated PNG files from the same concept:

- `icon-16.png`
- `icon-32.png`
- `icon-48.png`
- `icon-128.png`

Regenerate them with:

```bash
node scripts/generate-icons.js
```
